# Contributing ke Yomu

Terima kasih atas minat Anda untuk berkontribusi ke proyek **Yomu**! Kontribusi Anda sangat kami hargai — baik itu berupa perbaikan bug, fitur baru, dokumentasi, maupun laporan masalah.

## 📌 Contoh Cara Berkontribusi

### 1. Fork dan Clone Repositori
Mulai dengan membuat *fork* dari repositori ini, lalu clone ke lokal Anda:
```bash
git clone https://github.com/<username>/yomu.git
````

### 2. Buat Branch Baru

Gunakan nama branch yang deskriptif:

```bash
git checkout -b fix/navbar-responsive
```

### 3. Lakukan Perubahan dan Commit

Pastikan commit Anda ringkas dan jelas:

```bash
git commit -m "Fix: perbaikan tampilan responsif pada navbar"
```

### 4. Push dan Buat Pull Request

Push ke fork Anda dan buka Pull Request (PR) ke `main`:

```bash
git push origin fix/navbar-responsive
```

Lalu buka PR di GitHub dan jelaskan perubahan Anda secara singkat namun jelas.

---

## ✅ Kode Gaya dan Standar

* Gunakan JavaScript/TypeScript sesuai standar ESLint (jika tersedia).
* Gunakan format `camelCase` untuk variabel, `PascalCase` untuk komponen.
* Sertakan komentar jika logika yang ditulis tidak langsung jelas.

---

## 🧪 Testing

Jika proyek memiliki pengujian otomatis:

* Jalankan `npm run dev` (atau perintah setara) sebelum mengajukan PR.
* Tambahkan pengujian baru jika Anda menambahkan fitur baru.

---

## 🐛 Melaporkan Bug

Jika Anda tidak ingin langsung berkontribusi dengan kode, Anda tetap bisa membantu dengan melaporkan bug melalui [Issues](https://github.com/aaidilz/yomu/issues).

Pastikan laporan bug Anda menyertakan:

* Langkah-langkah reproduksi
* Hasil yang diharapkan vs hasil yang terjadi
* Screenshot/log jika relevan
* Informasi versi (jika tersedia)

---

## 💡 Saran Fitur

Buka issue dengan label `enhancement` untuk mengusulkan fitur baru. Jelaskan:

* Apa masalahnya?
* Apa solusi yang diusulkan?
* Referensi atau inspirasi (jika ada)

---

## 📃 Lisensi

Dengan berkontribusi, Anda menyetujui bahwa kontribusi Anda akan dirilis di bawah lisensi MIT yang sama dengan repositori ini.

---
