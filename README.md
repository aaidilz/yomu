# 📘 YOMU - Belajar Bahasa Jepang Dengan Mudah

**YOMU** adalah aplikasi edukasi sederhana yang dirancang untuk membantu pengguna belajar bahasa Jepang secara interaktif. Proyek ini dibuat menggunakan **React** dan **Firebase** sebagai backend. Cocok bagi pemula yang ingin memahami dasar-dasar bahasa Jepang melalui kamus pribadi, catatan, dan fitur interaktif lainnya.


## 🚀 Fitur Utama

- 📚 Catatan pribadi untuk kosakata
- 🔍 Kamus buatan pengguna
- ✍️ Input dan pengelompokan kata kerja/partikel
- ☁️ Penyimpanan data berbasis Firebase
- 🎨 Mode terang dan gelap (theme switch)
- 🤖 Rencana integrasi dengan AI (Gimini API)

---

## 🛠️ Setup Project

### 1. Clone Repository
```bash
git clone https://github.com/aaidilz/yomu.git
cd yomu
````

### 2. Install Dependencies

```bash
npm install
```

### 3. Konfigurasi `.env`

Buat file `.env` di direktori root dan isi seperti berikut:

```env
VITE_API_KEY="your-firebase-api-key"
VITE_AUTH_DOMAIN="your-auth-domain"
VITE_PROJECT_ID="your-project-id"
VITE_STORAGE_BUCKET="your-storage-bucket"
VITE_MESSAGING_SENDER_ID="your-messaging-sender-id"
VITE_APP_ID="your-app-id"
VITE_MEASUREMENT_ID="your-measurement-id"

# Gemini AI
VITE_AI_API_KEY="your-gemini-api-key"
```

### 4. Jalankan Project

```bash
npm run dev
```
